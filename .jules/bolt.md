- When building XML sitemaps relying on large datasets (like news articles), implement explicit `limit/offset` pagination in the database queries instead of unsafely inflating single-request limits.
- Break early from paginated sitemap generation loops if articles fall outside of the required temporal window (e.g., older than 48 hours) to prevent memory exhaustion and function timeouts.
- Cache-busting logic in Service Workers must be manually or automatically bumped via `CACHE_NAME` changes when releasing architectural updates.
- Test suites relying on mocked `fetch` responses must assert both the successful completion of the logic block and the exact HTTP status codes generated by the edge handlers.
